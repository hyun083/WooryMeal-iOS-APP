# WooryMeal
사내 메일로 공유되는 식단표를 모바일 앱으로 조회하기 위해 시작한 프로젝트입니다.


# 기능
- 주간 식단 정보 조회
- 사용자가 입력한 선호 키워드를 저장하여 해당 키워드가 들어간 메뉴는 강조하여 표시합니다.
